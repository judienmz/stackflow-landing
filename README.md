# StackFlow — Landing Page

Landing page satu halaman untuk tiga produk StackFlow: **ERP Marketplace**, **StackFlow POS**, dan **Finance Bot Telegram**. Dibuat dengan HTML/CSS/JS murni (tanpa build tool), jadi bisa langsung dibuka dari browser atau di-hosting di GitHub Pages.

## 🔗 Live Demo

```
https://judienmz.github.io/stackflow-landing/
```

*(ganti sesuai username & nama repo GitHub kamu setelah Pages aktif)*

## 📦 Isi

```
├── index.html   → seluruh landing page (HTML + CSS + JS dalam satu file)
└── README.md    → file ini
```

## 🛠️ Cara Edit

1. Klik `index.html` di repo ini
2. Klik ikon pensil (Edit this file) di kanan atas
3. Ubah teks/warna/link yang diperlukan
4. Scroll ke bawah, klik **Commit changes**
5. Perubahan otomatis live di URL GitHub Pages dalam 1-2 menit

## 🧩 Bagian yang bisa disesuaikan

| Bagian | Lokasi di `index.html` |
|---|---|
| Logo & tagline | `<nav>` dan bagian `<header class="hero">` |
| Copy hero (headline utama) | `<h1>` di dalam `.hero` |
| Fitur tiap produk | `<ul class="feature-list">` di masing-masing `<section>` |
| Link "Beli Sekarang" / "Checkout" | `<div class="cta-row">` di masing-masing produk |
| Varian Finance Bot (Pribadi/Grup) | `<div class="bot-variants">` |

## 🚀 Deploy ke GitHub Pages

1. Settings repo ini → **Pages**
2. Source: branch `main`, folder `/ (root)`
3. Save, tunggu 1-2 menit
4. URL live muncul di bagian atas halaman Pages
